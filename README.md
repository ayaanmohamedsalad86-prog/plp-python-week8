# Personal Mini-Toolkit

## Project Description
This project is a Python mini-toolkit that provides three useful tools: a simple calculator, a to-do list, and a number checker.

## Tools Included

1. **Simple Calculator:** Performs addition, subtraction, multiplication and division.
2. **To-Do List:** Allows users to add tasks and view their saved tasks.
3. **Number Checker:** Checks whether a number is positive, negative or zero.

## How to Run the Program

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or another Python editor.
4. Run the file `toolkit.py`.
5. Follow the numbered menu to select a tool.
6. Choose option 4 to quit the program.

## Concepts Practiced

- Variables and data types
- User input and output
- If, elif and else statements
- While and for loops
- Lists
- Functions of f-strings for displaying messages

## Project Reflection

The hardest part of this project was creating the menu loop and making sure each tool worked correctly. The part that required the most attention was handling different menu choices and invalid inputs. I learned how to use lists to store tasks and loops to repeat actions. I also improved my understanding of conditional statements. Testing each tool helped me identify and correct mistakes in my code. If I had one more week, I would add more tools, such as a password generator and a better task management system. Overall, this project helped me combine the Python concepts I have learned into one useful program.
